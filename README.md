## Precizări editoriale
„Coordonator executiv” descrie rolul organizatoric, în timp ce documentul inițial folosește titulatura „Secretar de Program”. Datele de debut sunt prezentate ca anunțuri/comunicări, fără a afirma numărul parohiilor participante. Materialele didactice originale nu sunt redistribuite în acest pachet, în așteptarea aprobării publicării.

## Publicare
Încărcați index.html în rădăcina unui repository separat și activați GitHub Pages din Settings → Pages. Verificați în browser și pe proiector înainte de utilizare.
